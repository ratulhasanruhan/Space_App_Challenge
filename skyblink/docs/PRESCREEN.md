# 4-minute pre-screen script

The 2026 Project Submission Guide is published on November 13. Until then, this script follows the 2025 judging criteria: Impact, Creativity, Validity, Relevance, and Presentation. Local pre-screens use a talk this length. The global upload has often been a much shorter demo, so check the November 13 guide before you submit the file to spaceappschallenge.org.

Record the browser full screen at http://localhost:3000. Speak English, or add English subtitles. Do not put the NASA logo, flag, or mission patches in the frame. Say that the sky is simulated. Do not say you found Planet X.

## Shot list (4:00)

| Time | On screen | Say |
| --- | --- | --- |
| 0:00–0:25 | Home. Let the blink play. | “SPHEREx will image the whole sky in infrared. The hard part is telling a real change from a trick of the filter. Its linear variable filters change wavelength across the detector. Blink two raw frames and you can compare a star to itself in a different color. That fake flicker looks like motion.” |
| 0:25–0:45 | Stay on the home sky. Point at the bright source. | “SkyBlink only pairs frames when the same place is seen at the same wavelength, on different nights. What you see is simulated, built for that problem. It is not a flight image. The bright source is the thing that moved.” |
| 0:45–1:15 | Click **Open this sky**. Pause once on Night 1, then let it reach Night 2. | “Night one. Night two. The stars stay. The source left.” |
| 1:15–1:40 | Click **Difference**. | “Subtract the two nights. Orange is where it was. Blue is where it arrived. That pair is a dipole. A star that never moved subtracts away.” |
| 1:40–2:15 | Click **Detective**. Leave the selected candidate on screen. | “Detective mode is the check. This candidate is at 1.25 microns. The signal-to-noise is on the card. The shape test passed, so it is not an obvious cosmic-ray hit. There is no catalog name. We call it a candidate. We do not call it a planet.” |
| 2:15–2:45 | Open **Physics**. Leave Planet X at 500 AU. | “Did we find Planet X? No. Reflected light falls as one over distance to the fourth. At 500 AU this body is about 77,000 times fainter than the same body at 30 AU. One exposure is the wrong net. This slider uses the same equations our tests check.” |
| 2:45–3:15 | Open **Academy**. | “The same path is a classroom. Six missions. A right answer pays experience once. Ranks run from Cadet to Principal Investigator, and the last mission is the honest limit. In Detective, Mark Real or Mark Fake files a case.” |
| 3:15–3:40 | Open **Proof**. | “On these simulated fields, bright injections came back 80 of 80. False alarms in pure noise were zero. Known objects came back 33 of 246. We print the partial number. Faint sources fall off the curve. That is the depth limit.” |
| 3:40–4:00 | Stay on Proof. | “SkyBlink is for a student, a teacher, and anyone who should see the test before the headline. Next is real IRSA cutouts in this same viewer. SPHEREx data via IRSA, DOI 10.26131/IRSA652.” |

## Before you record

- Rehearse once with a timer. The clicks happen inside the gaps, not on top of the sentences.
- One person talks. One person drives the mouse.
- On the project page, name every AI tool the team used. That disclosure belongs on the form.
